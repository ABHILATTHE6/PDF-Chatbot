# Project Status

## Current state

The repository is being developed as a portfolio-quality PDF question-answering project using a Retrieval-Augmented Generation (RAG) architecture.

### Completed

- Professional project README
- Contribution guidelines
- Initial project roadmap
- RAG architecture documentation
- Clear separation between planned capabilities and implemented functionality

### Next implementation milestones

1. Build the PDF ingestion pipeline.
2. Add text extraction and chunking.
3. Add embeddings and vector retrieval.
4. Integrate the LLM response layer.
5. Build the chat interface.
6. Add source citations and tests.
7. Add CI and deployment configuration.

## Development principle

Each milestone should be implemented as a small, testable change with clear documentation and a meaningful Git commit.
